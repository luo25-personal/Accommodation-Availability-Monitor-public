# Accommodation Availability Monitor

自動監控指定飯店在特定日期區間的空房狀態，一旦有空房釋出，就即時推播到 Discord。

## 動機

預計參加一場研討會，但會場附近的飯店幾乎都訂滿了，剩下的房間又很貴。
平價飯店偶爾會有取消的房間釋出，不過很快就會被訂走，一直手動刷新訂房頁面也不實際。所以我寫了這支腳本自動定時查詢，一有空房釋出就馬上通知我。

## 功能

- **以「行程」為單位監控**：每個行程可以設定多間飯店和一段入住日期區間，也能同時監控多個行程（例如「青森行」「東京行」）。
- **每日空房查詢**：分析訂房網頁背後使用的空房 API，直接取得每間飯店、每種房型、每天的空房數量，不用解析 HTML。
- **即時通知**：發現空房時，依「行程 → 飯店 → 房型 → 日期」整理成易讀的訊息，透過 Discord Webhook 推播；超過 Discord 字數上限時會自動分段送出。
- **穩定性設計**：
  - 請求失敗時自動重試（最多 3 次，間隔 10 秒），避免單次網路異常造成漏抓
  - 每次請求之間保留延遲，降低對目標網站的負擔
  - API 回應格式不符時給出明確錯誤訊息，方便在網站改版後快速定位問題
- **機密設定分離**：Webhook 網址等機密資訊放在不納入版本控制的本機設定檔，公開版本只保留佔位字串。

## 運作流程

```
讀取行程設定（飯店、日期區間、人數、吸菸/禁菸）
        │
        ▼
逐間飯店查詢空房 API ──失敗──▶ 重試（最多 3 次）
        │
        ▼
篩出日期區間內有空房的房型
        │
        ▼
依行程 / 飯店 / 房型分組，格式化訊息
        │
        ▼
Discord Webhook 推播通知
```

## 通知範例

以下為訊息格式示意（飯店名稱與數字為範例）：

```
🎉 發現空房！
🕐 查詢時間：2026-07-20 09:00

✈️ 【青森行】
🏨 ○○飯店 青森站前
┌ 房型：雙人房（禁菸）
│　2026-08-07：空房 2 間
│　2026-08-08：空房 1 間
└
```

## 使用技術

- **Python 3**
- **requests**：呼叫訂房 API 與 Discord Webhook
- **Discord Webhook**：通知推播
- **作業系統排程工具**：定時自動執行
